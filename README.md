# Customer Service Queue

A simple browser app that demonstrates a queue data structure using a customer service line. Customers are served in the order they join: first in, first out (FIFO).

## Use the app

Open the [Customer Service Queue website](https://kasefquaye12-ui.github.io/customer-service-queue/). Enter a customer name and select **Join the line**. Select **Serve next customer** to serve the person at the front of the queue. **Clear the line** removes everyone waiting.

## Queue operations

- `push()` adds a customer to the back of the queue.
- `shift()` removes the customer at the front.
- The waiting list shows each customer’s position.

The app is built with HTML, CSS, and JavaScript. It runs in a web browser and does not need installation.
